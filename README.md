# Thornfield Community Library Management System

React implementation of the BIWA2110 Web Application Development Assignment 1.

## Requirements covered
- React functional components and JSX
- `useState`, `useEffect`, `useMemo`, `useCallback`
- React Router navigation
- Controlled forms and validation
- Book CRUD
- Stock add/borrow transactions and transaction history
- Login and role-based admin user management
- Local Storage persistence
- Responsive UI with low-stock highlighting
- Reusable components: Layout, Sidebar, Toast, StatBox, BookCard

## Run the project

```bash
npm install
npm run dev
```

Open the local Vite address shown in the terminal.
